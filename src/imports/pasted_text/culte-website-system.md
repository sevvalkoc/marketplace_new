Build a complete website system for “CULTE.”, a premium curated marketplace / concept store. The website must feel bold, cool, product-first, and highly curated. The aesthetic should be clean, white-background, editorial, and platform-ready. Think premium concept store meets modern marketplace: easy to use, visually distinctive, and commercially sharp.

The website is not just a landing page. It must function as a real marketplace with:
• buyer browsing and shopping experience
• buyer login / account experience
• dedicated seller login
• seller dashboard for uploading and managing products
• category-based browsing structure
• fully connected pages and navigation
• reusable, downloadable components for all UI elements

—

Core Brand System:
• Brand Name: CULTE.
• Visual Tone: cool, bold, premium, open, contemporary, curated, editorial, product-led
• Background: pure white only across the website
• Logo / Display Typeface: Valibuk, all caps, heavy weight, with the period always included in CULTE.
• UI / Body Typeface: Poppins Medium / Regular
• Palette:
  • White #FFFFFF as the website ground at all times
  • Deep Navy #181E51 for navigation, headers, structural anchors
  • Burnt Orange #E17544 used only for primary CTAs, active states, or one accent per surface
  • Light Blue #C2DFED for soft cards, image backgrounds, section fills, empty states
  • Soft Peach #F19D73 for occasional editorial highlights only
  • Near-Black #0F0F0F for body text only
• Layout Direction: spacious, premium, easy to scan, highly usable, elegant without being cold
• Product presentation must feel selected and elevated, never mass-market

—

Design Language:
• Use a very clean, structured grid with open white space
• Large typography moments for hero and category headings
• Navigation should feel premium and strong, with CULTE. clearly visible
• Product cards should feel minimal, premium, and category-flexible
• Orange should appear sparingly and intentionally
• Light blue should soften the interface in image zones, cards, hovers, or curated content areas
• Avoid dark backgrounds, generic startup SaaS visuals, loud marketplace clutter, gradients, or overly playful UI
• The site must feel unique and innovative, but still intuitive and very easy to use

—

Technical / Build Direction:
• Build in a way that feels ready for Figma Make prototyping
• Use Tailwind CSS logic for spacing and layout thinking
• Keep spacing generous and premium
• Make desktop-first, but fully responsive
• Preserve clarity and usability on mobile
• Use subtle hover transitions only
• No excessive animation
• No overly rounded startup UI
• Keep corners either sharp or only very slightly rounded, depending on what looks most premium within the brand

Design a complete, connected marketplace website system for CULTE. including storefront, buyer account, seller portal, category system, product pages, and reusable UI kit.
