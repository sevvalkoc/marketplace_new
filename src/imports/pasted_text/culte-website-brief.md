Build a complete responsive website for “CULTE.”, a premium curated marketplace / concept store.

Use these reference directions as the design benchmark:
- the cool, fashion-forward, category-led confidence of PCFG
- the curated concept store structure of Dot Concept Store
- the scalable marketplace logic of Hipicon
But do NOT copy them. Create something more refined, more premium, more editorial, and more original.

CULTE. should feel like:
a white-background, design-led, highly curated concept store marketplace with strong taste, strong typography, selective product presentation, and intuitive shopping.

This must feel cool, modern, premium, and commercially sharp.
It should not feel like a generic Shopify theme, a startup SaaS landing page, or a cluttered marketplace.

—

CORE CREATIVE DIRECTION
Design a concept-store-meets-marketplace experience.
The site should combine:
- the visual confidence of a premium fashion / design brand
- the discoverability of a modern marketplace
- the editorial taste level of a curated store
- the usability of a strong ecommerce platform

The mood should be:
- crisp
- directional
- cool
- fashion-aware
- open
- premium
- confident
- not loud
- not cute
- not corporate
- not overly techy

Background must always be pure white.

—

BRAND SYSTEM
- Brand name: CULTE.
- Use a bold all-caps logotype style for CULTE.
- Typeface direction:
  - Valibuk-style heavy display for logo, nav, major titles, section labels, CTA words
  - Poppins for body copy, filters, forms, UI text, product info
- Palette:
  - White #FFFFFF main ground
  - Deep Navy #181E51 for navigation, anchors, selected structural areas
  - Burnt Orange #E17544 for CTA, active underline, hover accent, or one controlled action point per section
  - Light Blue #C2DFED for soft category surfaces, image blocks, cards, hover fields, or editorial support areas
  - Soft Peach #F19D73 only occasionally for campaign/editorial moments
  - Near-black #0F0F0F for body text only

Use orange sparingly and intelligently.
Use light blue as a cool softener.
Keep the overall result extremely premium and clean.

—

SITE GOAL
This is a real marketplace.
It must include:
- buyer browsing
- buyer account
- buyer login / signup
- seller login
- seller upload / management dashboard
- product categories
- designer / seller visibility
- search
- cart and checkout
- fully linked pages
- reusable components

But the public-facing site should feel like a premium concept store first, and a marketplace second.

—

IMPORTANT UX PRINCIPLE
Do NOT design this like a dashboard-led website.
Do NOT make the homepage feel functional and dry.
The homepage must feel editorial, stylish, and selective.

Think:
“a highly curated store where every category, product, and seller feels chosen”

not:
“a crowded platform listing everything”

—

HOMEPAGE STRUCTURE
Design a homepage with this rhythm:

1. Strong Editorial Hero
- full-width or near full-width
- bold left-aligned headline
- striking, clean campaign-style visual area or fashion / object-led hero image zone
- one orange CTA only
- one secondary text link
- hero should feel like a premium concept store campaign, not a startup hero

2. Immediate Category Entry
- bold category shortcuts directly under or integrated into hero
- categories should feel like curated entry worlds, not plain menu buttons
- example categories:
  - Women
  - Men
  - Home
  - Beauty
  - Objects
  - Kids

3. Featured Product Rail
- horizontal or grid-based section
- highly curated product cards
- clean product image, title, price, seller name
- premium spacing
- no noisy badges everywhere

4. New Arrivals
- another product rail or clean grid
- should feel fresh, desirable, selective

5. Featured Designers / Sellers
- make sellers feel visible and important
- seller cards should feel premium, not directory-like
- include “View Designer” / “Explore Seller”

6. Editorial Discovery Section
- something like “The Edit” or “Selected This Week”
- could combine image-led story blocks + product entry points
- should feel like a concept store magazine layer

7. Featured Categories / Shop by Mood
- visual tiles or cards
- category discovery should feel beautiful and easy

8. Trust / Curation Logic Section
- explain why CULTE. is different
- focus on curation, selection, taste, and trust
- this should be elegant and very short

9. Seller Invitation Block
- refined section inviting brands / designers / sellers to join
- include a clear pathway to seller login or seller application
- make this feel elevated, not B2B boring

10. Premium Footer
- categories
- about
- customer care
- seller panel link
- social
- newsletter
- legal

NAVIGATION DIRECTION
The header must be excellent.
It should feel closer to a premium concept store than a generic marketplace.

Include:
- CULTE. logo
- search
- category navigation
- account
- wishlist
- bag
- seller login link somewhere elegant, not too loud

Desktop nav should feel fashion / design retail inspired.
Mobile nav should be beautifully simplified.

Consider a refined mega menu for categories and designers.
The mega menu should feel premium, light, clean, and image-supported.

—

CATEGORY PAGE DIRECTION
Category pages should feel like premium discovery pages, not boring catalog dumps.

Each category page should include:
- strong category title
- optional short editorial intro
- filters
- sorting
- breadcrumbs
- product count
- product grid
- seller names visible on product cards
- optional category hero image or visual tile
- subcategory shortcuts

The visual rhythm should feel airy and elevated.

—

PRODUCT PAGE DIRECTION
Product pages must feel premium, modern, and trustworthy.

Include:
- large image gallery
- title
- price
- seller / designer attribution
- category breadcrumb
- add to bag
- wishlist
- details
- shipping / returns
- related products
- more from this seller
- trust signals
- sticky mobile CTA

Product pages should feel like a premium multibrand store, not a cheap aggregate listing page.

—

DESIGNER / SELLER PROFILE PAGE
This is very important.
The site should celebrate designers / sellers.

Create a seller page with:
- seller name
- intro
- brand story
- selected products
- categories they belong to
- visual banner or campaign image
- follow / save / explore actions if relevant

This page should feel editorial and credible.

—

SEARCH EXPERIENCE

Include:
- predictive search
- category suggestions
- designer suggestions
- product suggestions

The seller dashboard should be clean and easy, but still on-brand.

The add product flow should include:
- product title
- description
- category
- subcategory
- tags
- price
- SKU
- stock
- image upload
- shipping info
- save draft / publish
